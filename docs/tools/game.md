## HM-STEAM-TOOLS(Windows)
>
### 快速开始

1. 安装[Steam](https://store.steampowered.com/)官方游戏平台。
2. 下载入库管理工具[HM-STEAM-TOOLS](https://v6.gh-proxy.org/https://github.com/YS-CODE-GO/HM-STEAM-TOOLS/releases/download/4.0.16/HM-STEAM-TOOLS-v4.0.16-Built-in-3916.7z)并解压（*密码：yingshu*）运行，左侧 “解锁器&核心” 安装核心,选择或搜索游戏入库。
3. 到Steam库中下载、开始游戏。
