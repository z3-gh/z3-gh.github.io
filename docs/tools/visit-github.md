# 访问Github

## WattTookit（PC、Android）

>开源多功能工具箱，提供一键加速功能，可明显改善Github访问体验。

### 快速开始

安装运行[WattTookit](https://steampp.net/)，左侧选择"网络加速",在服务列表中，勾选"GitHub",点击"一键加速"按钮。

点击测试：[Github](https://github.com)

## Github Proxy（Web）

>GitHub 资源加速代理服务，通过全球分布式 CDN 节点与智能线路调度，解决国内及跨国网络中访问 GitHub 频繁出现的连接超时、克隆龟速、大文件下载中断等痛点。

### 快速开始

复制Github资源下载链接，粘贴到[Github加速](https://gh-proxy.com/)，转换链接加速下载。
