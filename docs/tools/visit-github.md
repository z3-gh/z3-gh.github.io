# 访问Github

## Github访问加速工具——WattTookit（全平台）

>本站部分资源需访问Github获取、使用，国内用户可用此工具加速访问。

### 使用方法

安装运行[WattTookit](https://steampp.net/)，左侧选择"网络加速",在服务列表中，勾选"GitHub",点击"一键加速"按钮。

点击测试：[Github](https://github.com)

## Github下载加速服务——Github Proxy（Web）

>GitHub Proxy 是一个专为开发者打造的高性能 GitHub 资源加速代理服务。它通过全球分布式 CDN 节点与智能线路调度，解决国内及跨国网络中访问 GitHub 频繁出现的连接超时、克隆龟速、大文件下载中断等痛点。

### 使用方法

复制Github资源下载链接，粘贴到[Github加速](https://gh-proxy.com/)，转换链接加速下载
