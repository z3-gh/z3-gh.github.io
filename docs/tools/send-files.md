# 传文件

## LocalSend（跨平台）

>免费开源的局域网文件传输工具，让您在不同设备之间安全、快速地共享文件，无需互联网，无需云端服务器。

### 快速开始
1. 下载安装 [LocalSend](https://localsend.org/zh-CN)或使用[网页版](https://web.localsend.org/zh-CN)，确保所有设备都连接到同一网络。

2. 在发送端选择文件，然后选择接收端发送。

3. 接收端点击确认，开始进行传输，完成后可在右上方历史中找到接收的文件。
