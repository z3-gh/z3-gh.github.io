# 传文件

## 局域网文件传输工具——LocalSend（全平台）

>免费开源的跨平台局域网文件传输工具，让您在不同设备之间安全、快速地共享文件，无需互联网，无需云端服务器。

### 使用方法

1. 在所有需要传输文件的设备上下载并安装 [LocalSend](https://localsend.org/)，确保所有设备都连接到同一个 Wi-Fi 或局域网。

2. 在发送设备上选择要传输的文件，然后选择接收设备。

3. 接收方点击确认，文件就会开始极速传输，完成后可在右上方历史中找到接收的文件。
