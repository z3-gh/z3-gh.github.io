# 音乐

## LX Music（Windows、macOS、Linux 和 Android）
>免费开源、干净无广告的多平台音乐聚合工具。

### 快速开始

1. 下载安装[LX Music](https://www.lxmusic.cn/)
2. 导入音源：复制 <CopyText text="https://dl.kstore.dev/download/7890/Hei+Music.js" tip="点击复制">音源</CopyText>，粘贴到LX Music设置-自定义源管理-导入-在线导入。导入后返回并勾选音源使其生效。
