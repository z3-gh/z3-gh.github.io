# 玩游戏(Windows)

1. 安装[Steam](https://store.steampowered.com/)官方游戏平台。
2. 访问[HM-STEAM-TOOLS](https://github.com/YS-CODE-GO/HM-STEAM-TOOLS/releases)下载解压（*密码：yingshu*）入库管理工具并运行，左侧 “解锁器&核心” 安装核心,选择或搜索游戏入库。
3. 到Steam库中下载、开始游戏。
