# 实用工具

## Steam、Github等加速工具

1. 下载并安装[Watt Toolkit](https://steampp.net/)。
2. 打开软件，左侧选择"网络加速",在服务列表中，勾选"GitHub",点击"一键加速"按钮。

>*本站部分资源需连接Github使用，国内用户可用此工具加速访问，或采用其它方式自行解决网络问题*

## 看视频

1. 下载安装[webhometv](https://github.com/fish2018/webhtv)
2. 打开[接口站](https://www.饭太硬.cc/)，点击复制接口，粘贴到影视app设置-点播-配置

## 看小说（Android）

1. 下载安装[阅读](https://github.com/HapeLee/legado-with-MD3)
2. 打开[书源](https://legado.aoaostar.com/)，一键导入。

## 看漫画、出版书

下载安装[Cmbok](https://bluemood.xiaomy.net/)，并导入漫画源。

## 玩游戏

1. 安装[Steam](https://store.steampowered.com/)官方游戏平台。
2. 访问[HM-STEAM-TOOLS](https://github.com/YS-CODE-GO/HM-STEAM-TOOLS)下载解压（密码：yingshu）入库管理工具并运行，选择或搜索游戏入库。
3. 运行steam，开始游戏。
